# astra_wii_game

**Blue Bay Golf** — an original, casual browser golf game with keyboard/mouse and local webcam swing controls.

The approved design combines a sunny coastal course, athletic customizable golfers, a compact cream club selector, a slim power bar, and minimap-only shot predictions.

## Development

Implementation is in progress. The complete scope is in [the goal prompt](docs/golf-goal-prompt.md). Design previews are in [docs/concepts](docs/concepts).

Requires Node.js 22.12 or newer. Run `npm install`, then `npm run dev`. Validation commands and camera setup instructions will be documented alongside the implementation.
